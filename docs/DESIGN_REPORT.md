# Design Report · 남강 GREEN MAP

요청한 Documents 및 Design Report 플러그인의 도구·템플릿이 현재 세션에 제공되지 않아 실제 템플릿을 적용하지 못했다. 이 문서는 저장소에서 관리하는 디자인 보고서이며 해당 템플릿을 사용했다는 의미가 아니다.

## 방향
‘가까운 곳에서 시작하는 조금 더 초록인 일상.’ 자연색의 차분한 지도 서비스. 매장 광고나 성과 수치 대신 근거와 검증 상태를 읽기 쉽게 제공한다.

## 시각 체계
- 주색: 숲 초록 #205c42, 보조색: 세이지·크림, 바탕: #fafbf8.
- 한글 시스템 폰트 우선. 외부 폰트·이미지 의존 없이 선형 아이콘과 CSS 도형을 사용한다.
- 소개 영역의 컵·자원순환·자전거 그림은 활동 유형을 설명하는 장식이며 특정 매장의 실제 활동 사진이 아니다.
- 후보 카드는 아이콘, 매장명, 주소, 활동 요약, 현장 확인 전 상태 순서.
- 포인트는 상세에서 별도의 옅은 초록색 정보 상자로 구분.

## 반응형
- 640px 이하: 가로 스크롤 필터, 지도/목록 선택, 하단에서 열리는 상세 화면.
- 넓은 화면: 목록과 지도를 함께 배치, 중앙 상세 대화상자.
- 매장 핀이 없는 이유와 외부 주소 검색을 지도 위에 안내한다.

## 접근성과 상태
문서 언어 ko, 의미 있는 제목 구조, 버튼·입력 이름, 필터 aria-pressed, 결과 개수 aria-live, 키보드 초점 표시. 네이티브 dialog로 초점 제한, Escape 닫기 및 닫은 후 초점 복귀. 검색 결과 없음·잘못된 상세 ID·타일 실패·클립보드 실패 상태를 제공한다. 자동 위치 수집을 하지 않는다.

## 다음 검토
현장 확인 후 활동을 단계별로 구분하는 데이터 구조, 검증일·확인자, 주소 좌표 대조, 매장 사진 게재 동의, 실제 주민 대상 사용성 검증을 추가한다.
