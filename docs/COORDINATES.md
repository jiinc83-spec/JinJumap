# 보고서 후보 주소 좌표 조회

`/?tool=coordinates`를 배포한 웹사이트 주소 뒤에 붙이면 주소 조사 도구가 열린다. `12곳 좌표 조회` 버튼으로 Kakao Maps JavaScript SDK의 services.Geocoder.addressSearch를 순차 호출한다. 실제 JavaScript 키와 등록된 웹 도메인, 카카오맵 사용 설정이 필요하다.

입력은 기존 보고서의 주소이며 괄호 안의 상가 설명만 검색에서 제외한다. 응답이 단일 결과일 때만 숫자 좌표를 표시한다. 복수 결과·검색 결과 없음·실패·시간 초과는 별도 상태로 유지한다. CSV로 다운로드할 수 있다. 위도(y)와 경도(x)를 구분한다.

주소 좌표는 건물·필지 위치다. 보고서의 매장이 현재 그 위치에서 영업한다는 증거가 아니다. 실제 매장 위치를 대조하기 전 후보 좌표를 production JSON에 자동 저장하지 않는다. 현장 검증 상태도 변경하지 않는다. 카카오의 최신 이용 조건에 따라 조회 결과의 보관·활용 범위를 확인해야 한다.

현재 클라우드의 적용된 네트워크 허용 목록에는 카카오 조회 도메인이 없어 이 환경에서 실제 12개 좌표를 수집하지 못했다. 도구의 응답 처리·빈 결과·내보내기는 격리된 모의 SDK 브라우저 테스트로 검사한다. 테스트 좌표는 실제 매장 데이터가 아니다.

## 사용자 제공 좌표 반영

2026-11-01 사용자 제공 자료의 10개 좌표를 `[위도, 경도]` 순서로 등록했다. 출처명은 제공된 표기 그대로 `coordinateSource`에 남겼으며 원문 URL은 제공되지 않아 추가하지 않았다. 출처 내용과 좌표는 독립적으로 재검증하지 않았다. 이디야커피·자연드림은 미확인으로 null을 유지했다. 현장 검증 상태는 모두 미실시다.

하삼동커피의 35.167373, 128.055881은 새평거로 75 평거휴먼시아4단지 대표 좌표다. 실제 매장 출입구와 차이가 있을 수 있다는 안내를 상세 화면에 표시한다. 지도 SDK 연결 시 등록된 좌표에 핀을 표시하며 길찾기는 해당 좌표를 사용한다. 위 주소 조회 도구는 조회 결과를 자동 저장하지 않는 별도 조사 도구로 유지한다.
