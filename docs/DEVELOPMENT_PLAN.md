# 남강 GREEN MAP 개발 계획과 화면 구조

## 목표와 범위
진주시 평거동 주민이 생활 속 탄소중립 실천 후보를 탐색하는 모바일 우선 React 웹 MVP. 로그인·데이터베이스·관리자 서버 없이 정적 데이터로 운영한다.

## 화면 구조
1. 홈: 프로젝트 소개와 실천지도 진입.
2. 탐색: 활동 유형 필터, 매장·주소 검색, 후보 개수, 지도, 후보 목록. 데스크톱은 좌측 목록·우측 지도, 모바일은 지도/목록 전환과 지도 아래 후보 목록.
3. 매장 상세: 해시 주소로 바로 열 수 있는 상세 대화상자. 매장명, 주소·복사, 조사된 활동, 참여 전 확인 방법, 포인트, 검증 상태, PDF 해당 쪽 및 인용 원문.
4. 이용 안내: 공개자료·브랜드 정책과 지점 실천의 구분, 방문 전 확인 기준.
5. 외부 연결: 카카오맵 주소 검색, Google Maps 도보 길찾기. 주소 기반이므로 목적지 확인을 안내.

## 단계
1. 조사자료 정리: 첨부 PDF 17쪽과 링크 주석을 읽고 후보 12개를 정적 JSON에 옮긴다. 원문 PDF를 함께 보관한다.
2. 화면 구현: 반응형 탐색, 필터·검색, 상세, 외부 연결. 다이얼로그 키보드 이동·Escape·초점 복원과 빈 결과 처리.
3. 지도: Leaflet + OpenStreetMap. 확인된 좌표·좌표 출처가 있는 매장만 핀으로 표시한다. 현재 자료에는 좌표가 없으므로 후보 목록에서 탐색하고 외부 지도에서 주소를 확인한다.
4. 검증: TypeScript 및 프로덕션 빌드, 데이터 제약 테스트, 모바일·데스크톱 브라우저 테스트.
5. 후속 작업: 주소의 실제 좌표와 출처를 수집·대조하고 현장조사 후 데이터 갱신. 지도 타일 이용정책과 배포 트래픽에 맞는 지도 공급자를 확정한다.

## 데이터 원칙
- 보고서 기준일: 2026-11-01. 전체 후보 12곳, 현장 검증 완료 0곳.
- 자료에 없는 매장·친환경 활동·감축량·인증·영업시간·전화번호·거리·좌표를 만들지 않는다.
- 브랜드 협약을 지점의 참여 가능 상태로 바꾸지 않는다.
- 탄소중립포인트와 브랜드 자체 할인을 구분한다. 금액은 보고서 기준이며 최신 요건을 확정하지 않는다.
- 인용 링크는 PDF에서 추출한 것이며 링크 대상 내용의 최신성은 별도 검증 전이다.

## 범위 밖
계정, 위치정보 수집, 자동 포인트 적립, 감축량 계산, 후기, DB, 인증된 매장 표시는 구현하지 않는다.
