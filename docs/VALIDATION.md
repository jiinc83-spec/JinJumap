# MVP 검증 결과

2026-11-01, Node.js 24.19.0, npm 11.9.0, 시스템 Chromium으로 검증.

- TypeScript 검사 및 Vite 프로덕션 빌드 통과.
- 데이터 제약 테스트 통과: 후보 12개, ID 중복 없음, 현장 검증 완료 없음, 좌표 미생성, 보고서 근거·참여 제안 존재, 포인트 대상 분류.
- Playwright 4건 통과: 데스크톱 1440×1000 및 모바일 390×844에서 검색·필터·빈 결과·상세·Escape 닫기·해시 직접 연결·원본 페이지 링크·길찾기 주소 전달·모바일 지도/목록 전환·가로 넘침 없음.
- 실행 서버의 PDF 응답이 저장된 원본 PDF와 바이트 단위로 동일함을 확인.
- 지도 패널 높이를 실제 브라우저에서 측정하고 목록으로 인한 패널 확장 문제 수정 후 테스트 재통과.

## 검증 한계

지도 타일 요청은 현재 환경에서 HTTP CONNECT 403으로 차단됨. `tile.openstreetmap.org`를 허용 도메인 설정 초안에 추가했으나 초안 저장은 현재 실행 환경에 대한 적용 또는 게시를 의미하지 않는다. 타일 표시 성공은 확인하지 못했다. 지도 실패 시 안내와 후보 목록·상세를 사용할 수 있다. 실제 좌표가 없으므로 매장 핀은 생성하지 않았다.

외부 원문 내용의 최신성, 외부 지도 서비스의 최종 길찾기 결과, 지점 실제 운영·혜택, 현장 검증은 수행하지 않았다. 브라우저 테스트는 링크의 올바른 목적지 주소 전달을 검증한다.

## 재사용 환경 설정

환경 초안에 install_script(npm ci·build·test), start_skill(실행·검증·데이터 원칙), 지도 타일 허용 도메인을 저장했다. 게시 및 새로운 작업에서의 복원은 검증되지 않았다.

## 제품 명세 반영 후 검증

카카오맵 SDK 연결 코드로 교체했으며 Leaflet 의존성을 제거했다. 카카오 키가 없는 준비 상태에서 목록·상세를 사용할 수 있음을 확인했다. 빌드 및 데이터/분류/좌표/카카오 링크 테스트가 통과했다. 브라우저 시나리오는 활동 분류와 빈 데이터 처리를 추가해 모바일·데스크톱 8건으로 확장했다. 실제 Kakao SDK 지도 표시는 키가 없어 검증하지 못했으며, 위 초기 OpenStreetMap 검증 기록은 현재 지도 공급자의 검증 결과가 아니다. 최신 설정과 남은 작업은 PRODUCT_SPEC.md 참고.

## 첨부 흐름도 반영

좌표 미제공과 외부 연결 창 열기 실패를 분리했다. 잘못된 매장 ID에서 탐색 복귀, 팝업 차단과 재시도, 좌표 없는 길찾기 안내를 브라우저에서 확인했다. SDK 로딩 실패와 재시도, 필터 변경 시 마커 제거, 마커에서 해당 매장 상세 열기는 외부 응답을 대체한 SDK 모의 테스트로 검사한다. 실제 매장 JSON에 좌표를 추가하지 않았다. FLOW_MVP.md에 흐름도와 화면의 대응 관계를 기록했다.
